\# Standardized Deployment Templates: Empirical Study



Research question: Do standardized self-service deployment templates

reduce developer cognitive load and time-to-deploy compared with

manual setup?



\## Structure

\- baseline/              manual setup (Dockerfile, Kubernetes YAML)

\- deployment-templates/  generator that creates a full service

\- generated/             sample generated output

\- results/               timing logs (pilot data)

\- docs/                  task sheet and study materials
